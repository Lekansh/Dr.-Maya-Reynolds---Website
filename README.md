# Dr. Maya Reynolds, PsyD — Practice Website

A modern, responsive, and editorial clinical psychology website designed for **Dr. Maya Reynolds, PsyD**, a licensed clinical psychologist based in Santa Monica, California.

---

## 🌿 About the Practice

Dr. Maya Reynolds provides therapy for adults navigating anxiety, panic, trauma, and burnout. Her work combines evidence-based methods (CBT, EMDR, mindfulness, and somatic practices) with deep reflection and grounded pacing.

- **Location:** 123th Street 45 W, Santa Monica, CA 90401
- **Care Modalities:** In-person sessions in Santa Monica & secure HIPAA-compliant telehealth across California.

---

## ✨ Design & Features

- **Color Palette:** Warm, editorial *Dusty Rose & Plum* aesthetic (`#705363` Plum, `#C48F91` Dusty Rose, `#F7F0EC` Blush Ivory).
- **Core Sections:**
  - **Hero Banner:** Grounding introduction, imagery, and direct call-to-action.
  - **About Dr. Maya Reynolds:** Narrative overview, clinical philosophy, and portrait.
  - **Who I Support:** Focus cards addressing Anxiety & Panic, Trauma & Past Experiences, and Burnout & High Internal Pressure.
  - **Interactive Specialties:** Styled tag pills highlighting clinical domains.
  - **Therapeutic Approach & Evidence-Based Modalities:** 4-pillar methodology showcasing CBT, EMDR, Somatic Regulation, and Mindful Grounding.
  - **Office & Telehealth Section:** *"A Space to Slow Down"* featuring photo tours of the Santa Monica practice suite and telehealth options.
  - **Footer & Practice Details:** Clear contact information, navigation links, and practice disclosures.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.

## 🚀 Local Development

To run and preview the website locally:

```bash
# Clone the repository
git clone https://github.com/Lekansh/Dr.-Maya-Reynolds---Website.git

# Navigate into the project folder
cd Dr.-Maya-Reynolds---Website

# Start a local HTTP server
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.

---

## 🌐 Deploy to Vercel

The repository includes a `vercel.json` configuration for static hosting.

1. Import the repository on [Vercel](https://vercel.com/new).
2. Keep the default settings and click **Deploy**.
3. Or deploy via CLI:
   ```bash
   npx vercel
   ```
